  COMO CONECTAR NO SERVIDOR
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
  [PC - Java]
  1. Abre o Minecraft Java Edition (TLauncher com perfil Fabric 26.2)
  2. Clica em Multijogador > Adicionar servidor
  3. Endereço: offers-nowhere.gl.joinmc.link:25565
  4. Entra no servidor
  5. Digite /register <senha> <senha> para criar conta
  6. Nas próximas vezes: /login <senha>

  [CELULAR - Bedrock]
  1. Abre o Minecraft (versão do celular)
  2. Clica em Jogar > Servidores > Adicionar servidor
  3. Endereço: offers-nowhere.gl.joinmc.link
  4. Porta: 19132
  5. Entra no servidor (login automático pelo Floodgate, sem senha)
  OBS: Seu nick no servidor será .SeuNick (com ponto na frente)

  LUCKPERMS - CARGOS E PERMISSÕES
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
  Cargos sugeridos (do menor para o maior):
  membro > vip > mod > admin > dono

  [CRIAR CARGO]
/lp creategroup <cargo>               - Criar cargo
  Exemplos:
  /lp creategroup membro
  /lp creategroup vip
  /lp creategroup mod
  /lp creategroup admin
  /lp creategroup dono

  [DAR CARGO A JOGADOR]
/lp user <nick> parent set <cargo>    - Dar cargo ao jogador
  Exemplos:
  /lp user Davizck parent set dono
  /lp user Davizck parent set admin
  /lp user Davizck parent set vip
  /lp user Davizck parent set membro

  [VER CARGO DO JOGADOR]
/lp user <nick> info                  - Ver cargo e permissões do jogador

  [REMOVER CARGO]
/lp user <nick> parent remove <cargo> - Remover cargo do jogador

  [HERANÇA DE CARGOS (cargo herda permissões de outro)]
/lp group <cargo> parent set <cargo_base>
  Exemplo: /lp group admin parent set mod
  (admin herda tudo que mod tem)

  [DAR PERMISSÃO ESPECÍFICA A CARGO]
/lp group <cargo> permission set <permissão> true
  Exemplo: /lp group vip permission set graves.teleport true

  [LISTAR CARGOS]
/lp listgroups                        - Ver todos os cargos criados

  [EDITOR WEB (mais fácil)]
/lp editor                            - Abre link para editar tudo pelo navegador

  [RECARREGAR]
/lp reload                            - Recarregar LuckPerms
